# ETOP Platform Core

Sprint 4A backend service.

## Routes

- `GET /api/v1/platform/health`
- `GET /api/v1/platform/registry`
- `GET /api/v1/platform/search?q=`

The initial search provider indexes registered ETOP modules. Future Sprint 4 providers can add customers, vendors, products, routes, warehouses, reports, documents, SQL, tasks, and notes behind the same response contract.
